# Fake-Review-Detection-Review-Intelligence-System


A machine learning and NLP application that estimates whether an online review resembles patterns typically associated with fake or genuine reviews.

Built with **scikit-learn**, **Sentence Transformers**, **NLTK**, **TextBlob**, and **Streamlit**.



---

## Overview

This project analyzes a review's text using multiple signals — TF-IDF features, sentence embeddings, statistical and linguistic patterns, sentiment, and similarity to a reference set — and combines them through a trained classifier to produce a **fake probability**, not a certainty. The goal is a realistic, explainable review-intelligence tool, not a black-box verdict machine.

> The system never claims a review is fake or genuine with certainty. It reports how closely a review resembles patterns learned from labeled training data, with supporting evidence for every prediction.

---

## Features

- **Text preprocessing** shared identically between training and inference (no train/serve skew)
- **TF-IDF** feature extraction (unigrams + bigrams)
- **Sentence embeddings** via Sentence Transformers for semantic similarity
- **15+ statistical and linguistic features** (punctuation ratios, capitalization, repetition, sentence length, etc.)
- **Sentiment analysis** (polarity and subjectivity)
- **Review similarity detection** against a reference collection
- **Rule-based suspicious pattern indicators** (presented as evidence, never proof)
- **Six model variants trained and compared automatically**: Logistic Regression, Linear SVM, Multinomial Naive Bayes, Random Forest, XGBoost, and combined feature ensembles
- **Automatic best-model selection** by F1-score on a held-out test set
- **Feature-level explanations** for individual predictions
- **Streamlit dashboard**: Home, Review Analyzer, Model Information, Batch Analysis (CSV upload/download), and visual Dashboard
- **Unit-tested** with pytest

## Getting Started

### 1. Clone and set up a virtual environment

```bash
git clone https://github.com/<your-username>/fake-review-detector.git
cd fake-review-detector
```

**Windows**
```bash
python -m venv venv
venv\Scripts\activate
```

**Linux / macOS**
```bash
python3 -m venv venv
source venv/bin/activate
```

### 2. Install dependencies

```bash
pip install --upgrade pip
pip install -r requirements.txt
```

### 3. Train the model

```bash
python scripts/train_model.py
```

Trains and compares all model variants, automatically selects the best one by F1-score, and saves the artifacts to `models/`.

Train on your own dataset instead of the bundled demo data:

```bash
python scripts/train_model.py --dataset data/raw/reviews.csv
```

### 4. Launch the app

```bash
python -m streamlit run run_app.py
```

Open the URL Streamlit prints (typically `http://localhost:8501`).

> Always launch through `run_app.py`, not `app/app.py` directly — Streamlit's module resolution otherwise conflicts with the `app` package name.

## Dataset Format

A CSV with a review column and a label column:

```csv
review,label
"The product works very well",0
"Absolutely perfect product, everyone must buy it",1
```

- `0` = Genuine, `1` = Fake
- Recognized review columns: `review`, `review_text`, `text`, `content`, `comment`
- Recognized label columns: `label`, `is_fake`, `fake`, `target`, `class`

If no dataset is placed in `data/raw/`, training automatically falls back to the small bundled demo dataset in `data/sample/` — useful for verifying the pipeline runs, **not** representative of real-world accuracy.

## Usage

**Review Analyzer** — paste a review, click Analyze, and get a prediction with probability, sentiment, statistics, similarity score, suspicious indicators, and the specific terms that influenced the decision.

**Batch Analysis** — upload a CSV of reviews, run analysis on all of them, and download the results.

**Model Information** — see the selected model, training metrics, and dataset stats.

**Dashboard** — visualize class distribution and batch-analysis results.

## Limitations

- The bundled demo dataset is small and synthetic; it exists to exercise the pipeline, not to demonstrate real-world accuracy.
- Sentence embeddings and similarity detection require downloading a model on first use and degrade gracefully (skip automatically) without internet access.
- Suspicious-pattern indicators are heuristic supporting evidence, not proof of deception.
- The similarity reference set is fixed at training time and does not update as new reviews are analyzed.
